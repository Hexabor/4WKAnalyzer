# 4Wks Analyzer

Aplicación de análisis de facturación y captación de tiendas. Código principal: este repositorio; versión interna en `js/changelog.js`. App existente: https://hexabor.github.io/4WKAnalyzer/.

[Árbol de fases](https://hexabor.github.io/4WKAnalyzer/docs/mapa-fases.html) · fuente `docs/mapa-fases.html` · [mantenimiento](docs/arbol-fases-mantenimiento.md).

El árbol agrupa entregas documentadas y propuestas de validación. Publicarlo no acredita aceptación de los frentes ni exactitud de cifras. Las pruebas de su publicación usan un contexto vacío, sin informes reales; la app restaura automáticamente `4wks_state` del navegador.
